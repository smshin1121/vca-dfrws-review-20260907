# Review materials

This snapshot accompanies *Reproducible Cross-Chain Tracing with Public Records*.
Download the archive below, verify its SHA-256, and extract it. The package README
contains the environment setup and relative commands for rerunning the analyses.

- [Review archive](VCA_anonymous_review_v4r2_20260907.zip)
- [SHA-256 checksum](SHA256SUMS)

The archive contains 10,285 files (55,550,843 compressed bytes). It preserves frozen
source and incident responses, configurations, reference outputs, replay checks,
the external sample frame and selection, first predictions, public chain records,
Bitcoin recipient-history searches, and the instrumented stopping-point diagnosis.

The first external result is 9 completed interpretations among 40 selected swaps;
all 31 unsupported inputs remain in the denominator. Interpretation of the nine
inputs agrees with the checked records. This does not establish general precision.
The historical recipient-history search finds 132 of 153 payments without receiving
Midgard payout identifiers or amounts. It is a retrospective development-case check.

The package README records the capture-timing and earlier-state preservation limits,
source provenance, anonymization transformations, and the commands actually tested.
It distinguishes local repeat runs from reproduction by another research team.
The first predictions, raw responses, and frozen decoder have not been tuned to
improve the 40-swap result.

Use the checksum to confirm that a hosting service has not transformed the archive.
